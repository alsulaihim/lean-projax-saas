# Marketing Website

**Port:** 3050  
**Framework:** Next.js 14+ (App Router)  
**Deployment:** Railway → leanprojax.com

## Purpose
Public-facing marketing website with landing page, pricing, and documentation.

## Features
- SEO-optimized landing page
- Pricing page with feature comparison
- About, Contact, Docs pages
- Links to app.leanprojax.com for signup/login

## Tech Stack
- Next.js 14+ (SSR for SEO)
- shadcn/ui components
- Tailwind CSS
- No authentication required

## Getting Started

```bash
cd apps/marketing
pnpm install
pnpm dev  # http://localhost:3050
```

## Environment Variables
See `.env.example` for required variables.
