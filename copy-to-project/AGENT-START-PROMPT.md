# Agent Start Prompt

> Copy this and send it at the start of EVERY new session

---

## 📋 Copy This Prompt:

```
Please read .ai/CLAUDE.md carefully - it contains your complete configuration,
role definition, and behavior contract for this project.

After reading, please:
1. Confirm you understand your role and behavior expectations
2. Read .ai/SESSION-CONTEXT.md for the current project state
3. Summarize what we're working on and what the next steps are
4. Ask if there are any questions before we proceed

Remember:
- NO shortcuts, placeholders, or workarounds
- Challenge me if I suggest problematic approaches
- Explain technical decisions in business terms
- Follow all quality gates before committing
- Update SESSION-CONTEXT.md at the end of our session
```

---

## 🔄 Alternative Shorter Version:

```
Read .ai/CLAUDE.md and .ai/SESSION-CONTEXT.md, then confirm you
understand your role and summarize where we are in the project.
```

---

## 💡 Tips:

- Use this at the START of every session
- Bookmark this file for easy access
- Adjust the wording to your preference
- The key is getting the agent to read CLAUDE.md first

---

## 🎯 What This Does:

This prompt ensures the agent:

- ✅ Loads your project configuration
- ✅ Understands its behavior contract
- ✅ Knows the current project state
- ✅ Starts with the right context
- ✅ Won't take shortcuts or agree blindly

Without this prompt, the agent starts "blank" each session.
With it, the agent is fully configured and context-aware.
